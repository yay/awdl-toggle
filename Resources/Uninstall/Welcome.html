Uninstall AWDL Toggle

This removes AWDL Toggle and its background helper, and restores AWDL for normal macOS use.

Before continuing: remove AWDL from Control Center and the menu bar using each control’s context menu. macOS may retain a disabled slot after the app is removed.

Click Install to run the uninstaller. macOS Installer uses installation labels for this removal package and requires administrator authentication.

The app will close. Control Center and other widgets may briefly reload.
